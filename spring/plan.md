## Spring Boot 6个月学习计划

# 总规划（6个月 ≈ 24周）
- 第1～8周：**入门（会写可用接口）**
- 第9～16周：**进阶（能做完整业务系统）**
- 第17～24周：**专家（能架构、性能、部署）**

# 第一阶段：入门（8周 : 2026.3.1 - 2025.5.1）
目标：能独立写 **CRUD + 接口 + 数据库**，像写前端 API 一样自然。

## 第1周：环境 & 基础语法  3.1-3.7
- 装 JDK + IDEA + Maven/Gradle
- Java 基础快速过（只学后端必用的）
  - 变量、循环、集合（List/Map）
  - 类、方法、注解
- 跑通第一个 Spring Boot 项目
- 输出：Hello World 接口

## 第2周：Spring Boot 核心 3.7-3.14
- 理解：IOC / DI / 注解
- 常用注解：`@Controller` `@RestController` `@Service` `@Autowired`
- 写 GET/POST 接口，接收参数
- 输出：3 个可用接口（查询/提交/参数校验）

## 第3周：持久层 & 数据库 3.15-3.20
- MySQL 基础（建库、建表、增删改查）
- MyBatis-Plus 或 JPA 任选（推荐 MP，上手快）
- 单表 CRUD
- 输出：用户表增删改查接口

## 第4周：请求、响应、参数校验 3.23-3.27
- 请求体、路径参数、查询参数
- 统一返回格式（前端最熟这块）
- 全局异常处理
- Validation 参数校验
- 输出：一套**规范后端接口结构**

## 第5周：业务层 + 事务 3.30-4.03
- 分层思想：Controller → Service → Mapper
- `@Transactional` 事务
- 简单业务逻辑（如：注册+记日志）
- 输出：带事务的注册/登录逻辑

## 第6周：登录与安全（JWT） 4.06-4.10
- JWT 登录流程
- 拦截器 / 过滤器
-  token 颁发、刷新、过期
- 输出：完整登录鉴权体系

## 第7周：整合 Redis  4.13-4.17
- Redis 安装 + 基础命令
- 缓存、分布式锁简单用
- 接口缓存优化
- 输出：带缓存的查询接口

## 第8周：阶段小项目（必做） 4.20-4.24
做一个**极简后台**：
- 用户登录
- 单表 CRUD
- 统一返回 + 异常处理
- 接口文档（Swagger/Knife4j）

**第一阶段结束：你已经是「能用的后端」**

---

# 第二阶段：进阶（8周 : 2026.5.1 - 2025.7.1）
目标：能做**企业级业务系统**，懂设计、懂规范、能协作。

## 第9周：项目结构 & 工程化
- 标准后端分层
- 配置管理（dev/test/prod）
- Maven/Gradle 依赖管理
- 日志规范

## 第10周：MyBatis/MP 高级 & 多表
- 关联查询、分页
- 动态 SQL
- 多表业务设计

## 第11周：设计模式 & 代码规范
- 后端常用模式：
  - 策略模式
  - 模板方法
  - 工厂模式
- 写出「可维护」的业务代码

## 第12周：异步 & 并发基础
- `@Async`
- 线程池
- 异步处理耗时任务

## 第13周：RabbitMQ / 消息队列入门
- 异步解耦思想（前端非常好理解）
- 简单使用：发送/接收消息
- 应用场景：短信、日志、通知

## 第14周：权限系统（RBAC）
- 角色、权限、菜单
- 接口权限控制
- 输出：后台权限骨架

## 第15周：接口文档 & 测试
- Swagger/Knife4j
- Postman 测试
- JUnit 单元测试

## 第16周：阶段大项目（必做）
做一个**完整管理后台后端**：
- 用户、角色、权限
- 业务模块（如文章/商品）
- 分页、条件查询、导出
- 统一异常、日志、鉴权

**第二阶段结束：你能独立负责一个后端微服务**

# 第三阶段：专家（8周 : 2026.7.1 - 2025.9.1）
目标：**架构思维 + 性能 + 部署 + 线上问题**
对标：能当后端技术负责人。

## 第17周：Spring Boot 原理
- 自动配置原理
- Spring Boot 启动流程
- 自定义 Starter

## 第18周：性能优化
- SQL 优化、索引
- 慢查询排查
- 接口耗时优化

## 第19周：高并发基础
- 缓存、降级、限流
- 分布式锁
- 接口幂等性

## 第20周：微服务基础（Spring Cloud）
- 微服务思想
- Nacos / Eureka 服务注册发现
- OpenFeign 远程调用

## 第21周：网关 & 配置中心
- Spring Cloud Gateway
- 配置中心
- 路由、过滤、限流

## 第22周：Docker & 容器化
- Docker 打包 Spring Boot
- Docker Compose
- 理解容器化部署

## 第23周：CI/CD & 部署上线
-  Jenkins / GitLab CI
- 测试 → 构建 → 部署
- 线上环境结构

## 第24周：专家级综合项目
做一个**微服务商城/后台系统**：
- 多服务拆分
- 远程调用
- 消息队列
- 缓存、分布式锁
- 容器化部署

**6个月结束：你 = 资深前端 + 准专家级后端**

# 给前端的特别建议
1. 把**接口、路由、组件、状态**对应到后端：
   - 接口 = Controller
   - 服务 = Service
   - 状态/数据 = DB + Redis
   - 组件复用 = 工具类 / 设计模式
2. 你工程化强，**Maven/Gradle、配置、部署**会学得极快。
3. 每周**必须输出代码**，不要只看视频。
